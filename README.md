# AIVory Smart Inference

Bug reports, feature requests, and discussions for [AIVory Smart Inference](https://aivory.net/smart-inference). Smart AI inference platform that continuously compares pricing across providers and spot GPUs, then routes your workloads to the cheapest reliable option.

## About

AI inference costs vary wildly across providers and fluctuate throughout the day. AIVory Smart Inference continuously compares pricing across providers, scores offers by cost, reliability, and risk, and routes your workloads to the best option available.

### What it does

- **LLM Inference Routing**: Routes hosted model API requests through the cheapest available provider with risk-aware scoring and automatic failover
- **GPU Spot Brokering**: Finds and provisions the cheapest spot GPUs across providers for custom model deployment
